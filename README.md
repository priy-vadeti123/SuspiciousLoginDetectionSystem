# Suspicious Login Activity Detection System

## Project Description
A Python and Streamlit web application that records login attempts and detects suspicious login activity.

## Features
- User and admin login
- Successful and failed login tracking
- Detection of repeated failed login attempts
- Suspicious activity alerts with severity levels
- Admin dashboard with search and filters
- SQLite database for storing login records

## Technologies Used
- Python
- Streamlit
- SQLite
- Pandas

## How to Run
Install dependencies:

`pip install -r requirements.txt`

Start the application:

`python -m streamlit run app.py`
